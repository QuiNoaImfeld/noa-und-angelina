# Noa & Angelina – Our Story

Eine persönliche Jahrestag-Webseite für uns.

## Live-Demo

💌 **[https://quinoaimfeld.github.io/noa-und-angelina/](https://quinoaimfeld.github.io/noa-und-angelina/)**

## Über dieses Projekt

Diese Webseite enthält:
- Ein Quiz mit persönlichen Fragen als Eingang
- Eine interaktive Zeitleiste ("Our Journey")
- Eine Foto-Galerie zum Durchswipen
- Unseren gemeinsamen Song
- Einen Beziehungslebenslauf mit rotierender Achse
- Einen Liebesbrief
- Ein Firework Lab zum Feiern

Gebaut mit HTML, CSS und Vanilla JavaScript (anime.js für Animationen, Leaflet für die Karte).
